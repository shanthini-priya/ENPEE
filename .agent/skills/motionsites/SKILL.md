# MotionSites AI - Website Animation & Design Intelligence

MotionSites brings motion design intelligence, GSAP animation presets, modern micro-interactions, responsive UI/UX architecture, and anti-slop frontend taste to build world-class web experiences.

## Core Capabilities
- **GSAP Animation Presets**: 17 production-ready presets covering hero reveals, scroll-driven tweens, micro-interactions, stagger cascades, modal transitions, and hover physics.
- **Motion Best Practices**: Context-aware timing (subtle 150-250ms, standard 300-500ms, grand 600-1000ms), easing curves (power2.out, cubic-bezier), and strict `prefers-reduced-motion` accessibility support.
- **Design Intelligence**: Searchable catalogue of 79 design styles, 192 product palettes, 74 font pairings, 119 UX guidelines, and 22 technology stacks.
- **Frontend Polish**: Anti-slop landing page layout rules, typography hierarchies, card aesthetics, and responsive layout resilience.
